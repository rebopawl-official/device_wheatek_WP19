# OUKITEL WP19 (Wheatek k85v1_64, MT6785) - recovery device tree

Generated by twrpdtgen from the stock recovery.img, then fixed by hand:
- super size 5242880000 (was a wrong auto-generated value)
- product makefiles: twrp_WP19 / fox_WP19 (vendor/twrp instead of vendor/omni)
- recovery.fstab: removed md1dsp and mmcblk0p1 (phone uses UFS)
- init.recovery.mt6785.rc: removed mtk_plpath_utils exec
- OrangeFox flags in vendorsetup.sh (screen 1080x2460)

Layout: non-A/B, boot header v2, separate recovery partition (32 MiB), dynamic partitions (super).
